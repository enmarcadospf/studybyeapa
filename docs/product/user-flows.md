# Flujos iniciales

## Estudiante

1. entra a la portada
2. explora el catalogo
3. revisa el detalle del curso
4. se registra
5. compra o se inscribe
6. entra a su area y continua lecciones
7. reserva una tutoria

## Profesor

1. inicia sesion
2. revisa tareas pendientes
3. publica contenido
4. atiende cohortes
5. administra tutorias

## Administrador

1. revisa alertas
2. valida pagos
3. aprueba cursos
4. monitorea crecimiento y soporte
